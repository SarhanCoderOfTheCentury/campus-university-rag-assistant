# Noor Skills Institute: courses and services
Status: reference
Version: 2.0
Effective: 2026-01-01

## Web Foundations
Web Foundations costs PKR 12,000 and lasts 6 weeks. Classes run on Saturdays from 10:00 to 13:00. Learners practise semantic HTML, responsive CSS, and basic browser JavaScript. No previous programming experience is required. The course includes a small personal webpage exercise and feedback on readable code. The fee covers teaching and scheduled laboratory access; it does not include a personal laptop.

## Python Basics
Python Basics costs PKR 15,000 and lasts 8 weeks. Classes run on Tuesdays and Thursdays from 18:00 to 20:00. Topics include variables, loops, functions, files, and simple debugging. Learners build a command-line utility using fictional input data. Basic computer literacy is required, while previous programming knowledge is optional. This course does not promise advanced machine learning proficiency.

## React Essentials
React Essentials costs PKR 18,000 and lasts 6 weeks. Learners must already understand JavaScript functions, arrays, and browser events. Lessons cover components, props, state, forms, and routing. The practical project is a small responsive application. The catalogue does not publish an exact timetable for React Essentials, so staff should avoid inventing its teaching days.

## SQL Foundations
SQL Foundations costs PKR 14,000 and lasts 5 weeks. The course covers table design, filtering, joins, grouping, and basic transactions. Exercises use fictional shop records and a local relational database. It is suitable for learners who understand spreadsheets but have not used SQL before. Database administration and production migration services are outside this course.

## Git Teamwork
Git Teamwork costs PKR 8,000 and lasts 3 weeks. Learners practise commits, branches, pull requests, conflict resolution, and collaborative review. A local practice repository is used before learners work on a shared exercise. The class does not require access to a private employer repository. Learners should use their own accounts without sharing credentials.

## UI Design Basics
UI Design Basics costs PKR 10,000 and lasts 4 weeks. Topics include spacing, typography, contrast, component consistency, and accessible form design. Learners create a small interface mockup and explain their choices. The institute supplies classroom exercises, but does not sell commercial design software licences as part of the fee.

## API Development
API Development costs PKR 20,000 and lasts 8 weeks. Learners need basic Python knowledge. Topics include HTTP methods, request validation, REST endpoints, error handling, and introductory API testing. The final exercise uses a local fictional library service. Public cloud hosting charges and production security audits are not included.

## Software Testing
Software Testing costs PKR 16,000 and lasts 6 weeks. Learners study test cases, boundary values, equivalence classes, defect reports, and small automated unit tests. Basic programming knowledge is recommended. The project evaluates a sample classroom application. It does not certify that a real commercial product is safe to release.
