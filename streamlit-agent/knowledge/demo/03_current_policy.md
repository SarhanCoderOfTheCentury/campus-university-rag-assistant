# Noor Skills Institute: admissions and learning policy
Status: current
Version: 2.0
Effective: 2026-01-01

## Application processing fee
The application processing fee is PKR 1,500 under policy version 2.0. It is separate from the course fee and is not credited against tuition. An application is reviewed after the required form and processing fee are received. Paying a processing fee does not guarantee admission, a seat, or a preferred timetable. Staff must not quote an archived amount for a current application.

## Attendance requirement
Learners must achieve at least 80% attendance to qualify for the course certificate under version 2.0. Attendance is recorded for scheduled teaching sessions. Completing assignments alone does not replace the attendance requirement. The operations guide explains how a learner requests correction of an incorrect attendance record. No automatic attendance waiver is promised by these documents.

## Standard refund window
A learner may request a tuition refund up to 7 calendar days before the course start date. The request must be submitted in writing with the enrollment reference and course name. The application processing fee remains non-refundable. The window is measured against the published start date, not the day the learner first attends. Staff should read the exception below before rejecting a request outside the standard window.

## Exception: institute cancellation
If the institute cancels a course before it starts, the learner receives a full tuition refund even outside the standard refund window. The application processing fee remains non-refundable. This cancellation exception applies when the institute cancels the course; it does not cover a learner simply changing their preferred timetable. Staff record the cancellation and refer the request to admissions.

## Exception: one emergency deferral
A learner with a documented medical emergency may request one deferral to the next available cohort, subject to coordinator approval. This is an exception to the standard rule that enrollment belongs to one cohort. It does not guarantee an immediate replacement seat or a cash refund. Sensitive medical records must be handled by authorized staff, not uploaded to this public demonstration chat.

## Assessment and version precedence
Certificates also require a passing assessment. The passing assessment score is 60%. Version 2.0 supersedes version 1.0 from 2026-01-01. Compare archived rules only when the question asks about earlier rules. The fee and attendance rules changed between those versions. The refund window remained unchanged. No hostel prices, guaranteed salaries, or director personal contact number are published in these documents.
