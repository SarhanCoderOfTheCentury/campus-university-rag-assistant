# Noor Skills Institute: archived admissions policy
Status: archived
Version: 1.0
Effective: 2025-01-01
Superseded: 2026-01-01

## Archived application processing fee
Under archived policy version 1.0, the application processing fee was PKR 1,000. This amount applied during the fictional 2025 policy period and is retained only for historical questions. It must not be presented as the amount for a current application. The current version is stored in the separate current policy document, which establishes the replacement amount and its effective date.

## Archived attendance requirement
Under archived policy version 1.0, learners needed at least 75% attendance for certificate eligibility. This older threshold was replaced when version 2.0 became effective. A question comparing policies should show both thresholds, identify their versions, and explain the effective date. Staff must not combine the archived attendance threshold with a current fee and call the mixture one policy.

## Archived refund window
Version 1.0 allowed tuition refund requests up to 7 calendar days before the course start date. The application processing fee was non-refundable. This document is preserved so learners can distinguish an unchanged refund window from the two rules that actually changed. A comparison must not invent a refund-policy revision merely because the processing fee and attendance requirement changed.

## How to interpret this archive
This is a deliberately fictional, authenticated-in-scenario earlier version for classroom testing. It supplies explicit dates and status so metadata filtering can be demonstrated without guessing a historical sequence. It is unrelated to DSU snapshots, whose capture dates and earlier policy versions have not been authenticated. Switching datasets must never blend these fictional rules into a real university answer. The archive is searchable for historical requests and excluded from default current-policy retrieval.
